Мои стартапы

Мы работаем для того, чтобы технические специалисты становились уверенными AI–фаундерами. Наши подопечные — это не просто стартапы. Это команды, которые прошли архитектурные ревью, получили пайплайны данных и внедрили ответственный ИИ до выхода в прод. Ниже — проекты, которые сегодня строятся при нашей поддержке.

1. МедИИ — диагноз по симптомам с объяснением.

2. ЕдуТутор — адаптивный ИИ репетитор по математике.

3. ФинЧек — детекция аномалий в платежах.

4. Код2Док — автодокументация устаревшего кода.

5. Специалист по продажам — генерация коммерческих предложений.

6. СаппортБот Про — L2 поддержка для SaaS.
